# Y2mp3 - YouTube Music Downloader

A simple and powerful Python script for searching, listening to, and downloading music from YouTube.

## Features
- Search for tracks
- Listen with mpv
- Download in MP3 format
- Automatic dependency installation
- Works great in Termux

## Installation
```bash
pip install -r requirements.txt
python yt2mus.py
```

## Usage
Just run the script and follow the prompts.

## Requirements
- Python 3
- mpv, yt-dlp, ffmpeg (for Termux: `pkg install mpv yt-dlp ffmpeg`)
